# Simple Univer: жүктеу беті

https://sssox.github.io/SimpleUniver/ сайты univer.kaznu.kz сайтының бейресми клиенті Simple Univer қолданбасын жүктеп алуға көмектеседі. Ол келушінің жүйесін өзі анықтап, қажет файлды ұсынады:

- Windows 10 және 11 (Modern) немесе Windows 7, 8 және 8.1 (Legacy), 64 немесе 32 биттік, орнатушы немесе portable ZIP;
- Android, телефонға арналған QR-коды бар APK файлы;
- жүйеге қолданба жоқ болса (macOS, Linux, ChromeOS, ARM-дағы Windows), Chrome, Edge және Firefox кеңейтуі.

Әр файлдың өлшемі мен SHA-256 сомасы көрсетілген. Бетте скриншоттар, жиі қойылатын сұрақтарға жауаптар және дүкендер талап ететін [кеңейтудің құпиялылық саясаты](https://sssox.github.io/SimpleUniver/privacy/) бар.

Қолданбалардың өзі және олардың коды басқа репозиторийлерде:

- Windows және кеңейту: [SSSox/Simple-UniverKazNU-Desktop](https://github.com/SSSox/Simple-UniverKazNU-Desktop)
- Android: [SSSox/Simple-UniverKazNU-Android](https://github.com/SSSox/Simple-UniverKazNU-Android)

## Сайт қалай жасалған

Фреймворксіз және тәуелділіксіз қарапайым HTML, CSS және JavaScript. Сайт бөгде қаріптерді, скриптерді және санағыштарды жүктемейді: келушінің браузері тек sssox.github.io сайтына жүгінеді, ал файлдарды GitHub-тан жүктейді.

| Жол | Не бар |
|---|---|
| `site/index.html` | жүктеу беті; орысша мәтін тікелей HTML ішінде, JavaScript-сіз де көрінеді |
| `site/assets/strings.js` | орыс, қазақ және ағылшын тіліндегі мәтіндер |
| `site/assets/detect.js` | жүйе мен разрядтылықты анықтау |
| `site/assets/site.js` | тіл, қойындылар, файл сілтемелері, галерея |
| `site/privacy/` | кеңейту саясаты үш тілде, статикалық HTML |
| `site/data/releases.json` | соңғы шығарылымдар туралы деректер; құрастыру кезінде жасалады |
| `scripts/releases.mjs` | соңғы шығарылымдарды GitHub API арқылы оқып, `releases.json` жазады |
| `stores.json` | дүкендердегі кеңейту сілтемелері |

Сайт шығарылым деректерін келушінің браузерінде емес, құрастыру кезінде алады. Университет желісінде көп студент интернетке бір мекенжайдан шығады, ал токенсіз GitHub API сағатына тек 60 сұрауға рұқсат береді.

## Өз компьютеріңізде іске қосу

Node.js 22 немесе одан жаңа нұсқасы керек.

```bash
node --test "tests/*.test.mjs"
```

```bash
node scripts/releases.mjs
```

```bash
node scripts/serve.mjs
```

Бірінші команда тесттерді іске қосады: жүйені анықтау, API жауаптарын талдау, үш тілдегі мәтіндердің сәйкестігі. Екіншісі шығарылым деректерін `site/data/releases.json` файлына жүктейді; `GITHUB_TOKEN` айнымалысымен сұрау шегі жоғарырақ. Үшіншісі сайтты http://127.0.0.1:8780/SimpleUniver/ мекенжайында ашады (портты бірінші аргумент ретінде беруге болады).

## Жариялау

`.github/workflows/pages.yml` workflow-ы сайтты тексеріп, шығарылым деректерін жинайды және `site` бумасын GitHub Pages-ке жариялайды. Ол `main` тармағына әр push жасалғаннан кейін, әр 6 сағат сайын және Actions қойындысындағы «Run workflow» батырмасымен қолмен іске қосылады. Қолданбаның жаңа шығарылымы сайтта 6 сағаттан кешіктірмей пайда болады.

GitHub API жауап бермесе, құрастыру қатемен тоқтайды және сайтта алдыңғы нұсқасы қалады.
